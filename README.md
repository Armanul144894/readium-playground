# Bookly eBooks

Bookly eBooks is a responsive Next.js storefront for browsing and reading curated eBooks from the Bookly catalog API.

## Features

- Bookly-powered home page, products page, category pages, author pages, and product detail pages.
- Human-readable URLs based on category names, author names, and product names.
- Responsive Tailwind CSS UI for mobile, tablet, and desktop.
- Readium-powered reader routes for available EPUB files.

## Getting Started

- Install dependencies: `pnpm install`
- Start the development server: `pnpm dev`
- Open [http://localhost:3000](http://localhost:3000)
